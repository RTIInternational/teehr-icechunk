# teehr-icechunk

Build, keep up to date and read analysis-ready [Icechunk](https://icechunk.io) datasets of hydrologic and weather data, gridded or per feature, straight from the source files. Also computes zonal statistics (e.g. mean areal values) from them.

**Status:** under construction. The shared gridded code from TEEHR's deployments (teehr-hub, teehr-fved) is being moved here.
